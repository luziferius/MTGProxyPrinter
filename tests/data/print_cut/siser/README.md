# Minimal Siser vector reference evidence

These three PDFs were exported from Leonardo Design Studio 1.1.31 by Wayne
(bigntazt) from synthetic contour/vector probes. They contain registration bars
and card-outline probes, without card artwork or redistributed fonts.

The JSON records retain the original full-precision bar measurements and nominal
versus emitted frame distinctions used by test_siser_page_marks.py. Source PDF
SHA-256 hashes are recorded alongside the measurements. The Letter nine-card
reference and numeric-placement Letter/A4 references are distinct acquisitions.
The repeated/shifted acquisitions, native LDS files, screenshots, probe tools
and milestone investigations are omitted because these tests do not need them.

Reduced from accepted source 839dba6c86647dc154f62fb37f16761460c9fae8
in bigntazt/MTGProxyPrinter-Siser, retaining measured values unchanged.
These are software/reference observations, not a universal cutter accuracy
specification or compensation. Development was AI-assisted.
